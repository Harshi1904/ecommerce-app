# ecommerce-app
# 🛒 Ecommerce App (MERN Stack)

A full-stack Ecommerce web application built using **MongoDB, Express.js, React.js, and Node.js (MERN Stack)**.  
It provides basic shopping cart functionality with a working backend API and React frontend.

---

## 🚀 Features

- 🛍️ Product listing
- 🛒 Add to cart functionality
- ❌ Remove from cart
- 🔄 Real-time cart updates
- 🌐 REST API backend
- 🗄️ MongoDB database integration
- ⚡ React frontend UI

---

## 🏗️ Tech Stack

**Frontend:**
- React.js
- Axios
- CSS

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose
